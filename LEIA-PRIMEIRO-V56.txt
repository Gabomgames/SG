PAGAMENTOS
Para dinheiro real, configure e publique as Firebase Functions com:
- MERCADO_PAGO_ACCESS_TOKEN
- MERCADO_PAGO_WEBHOOK_SECRET
Também mantenha os demais secrets já usados pelo projeto (Steam, RAWG, Resend, Giphy etc.).

IMPORTANTE SOBRE NOW MARK
O checkout registra compra, taxa da plataforma e líquido do vendedor. O repasse automático para vendedores exige onboarding/OAuth de Marketplace do provedor de pagamento. Enquanto isso, o projeto mantém payoutStatus=pending_manual para não simular split automático.

PUBLICAÇÃO RECOMENDADA
1. Instale Node.js compatível.
2. Abra PowerShell na pasta do projeto.
3. Execute .\PUBLICAR-V56.ps1
O script instala dependências se necessário, verifica, gera dist, publica Worker e publica Hosting + Firestore + Storage + Functions.
