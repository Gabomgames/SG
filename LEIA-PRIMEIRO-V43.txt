ANTES DE PUBLICAR O RECAPTCHA V2:
1. Crie chave reCAPTCHA v2 Checkbox para something-gamer.web.app e something-gamer.firebaseapp.com.
2. Em config.js, substitua COLE_AQUI_A_SITE_KEY_RECAPTCHA_V2 pela Site Key pública.
3. No Worker: npx wrangler secret put RECAPTCHA_V2_SECRET
4. Na pasta something-gamer-api: npx wrangler deploy

SITE:
- npm run verificar
- npm run build
- firebase deploy --only hosting,firestore:rules,firestore:indexes

OBSERVAÇÃO:
- O projeto mantém Firebase Storage fora do fluxo do chat para não exigir configuração paga.
- Fotos/áudios do chat são limitados para caber com segurança no documento do Firestore.
- O projeto Electron e Android continuam nas pastas desktop-app/ e android-app/.
